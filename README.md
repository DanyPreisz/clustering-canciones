# Clustering de Canciones

Proyecto de clustering listo para Google Colab. Incluye EDA, Elbow, Silhouette y K-Means.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/clustering-canciones/blob/main/clustering_canciones_colab.ipynb)

## Contenido

- Simulación de features de audio
- EDA (histogramas, scatter)
- Elbow + Silhouette para elegir k
- K-Means final
- Visualización de clusters
- Perfil de segmentos
- Conclusiones

Dataset: datos simulados de canciones
